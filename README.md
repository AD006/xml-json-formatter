# Smart XML / JSON Formatter v3.0

A powerful web-based tool to beautify, format, and analyze XML and JSON data with an AI chat assistant (Jarvis).

![Version](https://img.shields.io/badge/version-3.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

- **Beautify** - Instantly format XML & JSON with proper indentation
- **Compare Mode** - Side-by-side comparison with diff highlighting
- **AI Assistant (Jarvis)** - Ask questions about your data in natural language
- **Themes** - Multiple editor themes (Light, Dark, Monokai, etc.)
- **Keyboard Shortcuts** - Ctrl+S (save), Ctrl+Z (undo), Ctrl+F (find)
- **Code Folding** - Expand/collapse sections
- **File Operations** - Upload and download XML/JSON files

## 🛠️ Technologies

- **Ace Editor** - Professional code editor with syntax highlighting
- **Custom XML Formatter** - Lightweight native formatter
- **Pure JavaScript** - No frameworks, fast and lightweight

## 📋 Usage

1. Paste your XML or JSON code
2. Click **Beautify** to format
3. Use **Ctrl+S** to download
4. Click **💬** to chat with Jarvis about your data
